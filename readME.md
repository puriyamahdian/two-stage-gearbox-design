\## 📋 معرفی پروژه



این مخزن شامل مستندات، محاسبات تحلیلی و نتایج طراحی \*\*فاز اول پروژه طراحی گیربکس\*\* از درس \*\*طراحی اجزا ۲\*\* (دانشگاه صنعتی شریف - نیم‌سال اول ۱۴۰۶-۱۴۰۵) است. هدف اصلی این پروژه، طراحی یک سیستم انتقال قدرت دو مرحله‌ای شامل یک جفت چرخ‌دنده \*\*هلیکال (مارپیچ)\*\* و یک جفت چرخ‌دنده \*\*مخروطی مستقیم (Straight Bevel)\*\* جهت به حرکت درآوردن یک نوار نقاله صنعتی با دبی بارگذاری متغیر است.



\### 🎯 اهداف کلیدی و محدودیت‌های طراحی

\* \*\*عمر کاری طراحی:\*\* ۱۵ سال (۲۵۰ روز در سال، ۸ ساعت در روز — معادل $1.8 \\times 10^8$ سیکل کاری / عمر بی‌نهایت)

\* \*\*سرعت دوران خروجی هدف:\*\* $100\\text{ rpm}$ (با حداکثر خطای مجاز کمتر از $2\\%$)

\* \*\*محدوده نسبت تبدیل هر مرحله:\*\* بین $2$ تا $5$ با رعایت \*\*شرط شکارچی (Hunting Tooth)\*\* و \*\*عدم تداخل هندسی\*\*

\* \*\*معیارهای استحکامی:\*\* طراحی بر اساس \*\*خستگی خمشی (Bending Fatigue)\*\* و \*\*خستگی سطحی / حفره‌دار شدن (Surface Pitting)\*\* مطابق استاندارد AGMA

\### ⚡ انتخاب الکتروموتور

با در نظر گرفتن راندمان کل گیربکس ($\\eta\_g = 95\\%$)، حداقل توان ورودی مورد نیاز برابر با $4.079\\text{ kW}$ محاسبه شد. جهت ایجاد حاشیه اطمینان مناسب، موتور استاندارد زیر انتخاب گردید:

\* \*\*نوع موتور:\*\* الکتروموتور سه فاز قفس سنجابی پوسته آلومینیومی (استاندارد IEC - کلاس بازده IE2)

\* \*\*توان نامی:\*\* $5.5\\text{ kW}$ ($7.5\\text{ hp}$)

\* \*\*سرعت نامی:\*\* $1455\\text{ rpm}$ (۴ قطب، فرکانس $50\\text{ Hz}$)
